# Unidad1_T1.2 — Memoria estática y dinámica

Proyecto académico en C# que explora el manejo de **memoria estática y dinámica**.

## Contenido

La solución separa los ejemplos en `MemoriaEstatica` y `MemoriaDinamica`, con una aplicación Windows Forms como punto de entrada.

## Requisitos

- Visual Studio con soporte para C# y Windows Forms.
- .NET compatible con `Unidad1_T1.2.csproj`.

## Ejecución

Abre `Unidad1_T1.2.sln` en Visual Studio y ejecuta el proyecto.

## Propósito

Practicar los conceptos de memoria estática y dinámica mediante ejemplos organizados por tema.
